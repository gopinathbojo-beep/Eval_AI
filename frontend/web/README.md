# ADEM Web

The web app for schools: teachers create exams, upload papers, keys and answer sheets, review AI marks and print
results; school managers oversee every exam in their school (view only). React + TypeScript + Vite + Tailwind.

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api to the backend on :8000
npm run build      # type-check + production build
```
