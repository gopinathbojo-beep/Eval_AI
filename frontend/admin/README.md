# ADEM Admin

The Platform Admin console: schools, parents, credits, payments, evaluations, question papers, disputes,
support, audit log and settings. React + TypeScript + Vite + Tailwind.

```bash
npm install
npm run dev        # http://localhost:5174, proxies /api to the backend on :8000
npm run build      # type-check + production build
```

Sign-in uses the `admin` portal: only Platform Admin accounts work here. Dev account: admin@adem.local / ChangeMe123.
